# 更新记录

## 0.2.4 — 2026-09-28

- 将配图升级为与博客配套的黑白实验出版物风格：石墨黑与暖纸白两种底色、精密线条、抽象几何和少量陶土红。
- 新增“选择配图用途与底色”，支持正文、概念图和系列封面；保留文字模型独立配置。
- 最终请求固定加入视觉规范，百炼生图可携带内置参考图，减少构图与风格漂移。

## 0.2.3 — 2026-09-28

- 新增百炼 Token Plan 生图配置入口，预设 Qwen Image 3.0 Pro 和 1K 横图；文字模型配置独立保留。
- 使用套餐专用 DashScope 生图接口，适配嵌套请求、尺寸格式和图片响应；密钥保存在 SecretStorage，图片下载不携带密钥。

## 0.2.2 — 2026-09-28

- 文章可直接加入系列，分组改为可选；侧栏、新建和移动菜单与网站阅读目录同步支持。
- 本地系列预览支持拖拽排序、跨系列和分组移动、移出系列，以及手机和键盘操作菜单。
- 拖拽自动写回目录，检查并发修改；编辑接口仅接受当前本地预览会话，正式网站不含编辑入口。

## 0.2.1 — 2026-09-28

- 适配硅基流动原生生图参数与图片下载响应，保持 API 密钥仅发送给配置的接口。
- 增加 Qwen-Image 推荐尺寸，沿用统一插图风格；文字补全和生图可共用同一接口密钥。
- 文字模型可先将选区整理为画面构思，减少生图把原文和颜色代码直接画进图中的情况；硅基流动补全使用即时响应模式。

## 0.2.0 — 2026-09-28

- 新增系列、组、新建文章、已有文章分组、阅读顺序调整，以及“研究手记”侧栏。
- 命令面板可直接启动博客预览与构建检查。
- 按选中文字生成统一风格 AI 配图，支持独立配置、SecretStorage、取消、超时及文章改动保护。
- 网站新增系列目录与组内阅读导航，正式构建排除草稿。

## 0.1.0 — 2026-09-12

首个公开 GitHub 安装包。

- 通过独立 LSP 提供中文双链、文章别名和章节补全、跳转、悬停及引用查找。
- 检查 TOML frontmatter、主要元数据类型、失效双链、同名目标、缺失章节和公开文章指向草稿的链接。
- tags 支持多行补全、中文显示名、使用次数、引用查找和重复标签诊断。
- 图形组件补全文章目录下的 Typst 源文件，F12 可跳转；配套 Tinymist 处理 `.typ` 语言服务。
- 可选 AI 行内补全支持公式、围栏代码块和 Typst；使用用户配置的 OpenAI 兼容接口，密钥存储于 VS Code SecretStorage。
- 提供文章、双链和图形片段，以及重启语言服务和管理 AI 密钥的命令。
- 提供 Windows / Linux 自动构建、LSP 和 AI 接口测试及 VSIX 构建产物。

已知边界：AI 默认关闭，真实模型需自行配置；不自动重命名双链；中文章节建议使用标题或显式 `{#id}`，不推断 Zola 自动音译的中文锚点。完整使用说明见 [README](README.md)。
